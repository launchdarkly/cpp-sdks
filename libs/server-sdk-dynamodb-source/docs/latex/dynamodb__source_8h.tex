LDServer\+Lazy\+Load\+Dynamo\+DBSource represents a data source for the Server-\/\+Side SDK backed by Amazon Dynamo\+DB. It is meant to be used in place of the standard Launch\+Darkly Streaming or Polling data sources. 

Call \mbox{\hyperlink{dynamodb__source_8h_a003149b72c9cbbd3c9a4780f988b2c5c}{LDServer\+Lazy\+Load\+Dynamo\+DBSource\+\_\+\+New}} to obtain a new instance. This instance can be passed into the SDK\textquotesingle{}s Data\+System configuration via the Lazy\+Load builder.

The Dynamo\+DB table must already exist and follow the Launch\+Darkly schema\+: a String partition key named {\ttfamily namespace} and a String sort key named {\ttfamily key}. The Launch\+Darkly Relay Proxy populates the table with this schema; this source only reads from it.

Creates a new Dynamo\+DB data source suitable for usage in the SDK\textquotesingle{}s Lazy Load data system. 

In this system, the SDK will query Dynamo\+DB for flag/segment data as required, with an in-\/memory cache to reduce the number of queries.

Data is never written back to Dynamo\+DB by the SDK; the Launch\+Darkly Relay Proxy populates the table.


\begin{DoxyParams}{Parameters}
{\em table\+\_\+name} & Name of the Dynamo\+DB table to read from. The table must already exist; this function does not create it. Must not be NULL.\\
\hline
{\em prefix} & Prefix to use when reading SDK data from Dynamo\+DB. This allows multiple SDK environments to coexist in the same table. Must not be NULL.\\
\hline
{\em options} & Optional AWS Dynamo\+DB client configuration. When non-\/\+NULL, the builder is consumed and freed by this function; do not call \mbox{\hyperlink{dynamodb__client__options_8h_ad01433c5bb604ccdfe6952a7b3f0cb94}{LDServer\+Dynamo\+DBClient\+Options\+Builder\+\_\+\+Free}} on it afterward. When NULL, the AWS SDK\textquotesingle{}s default provider chain is used for region, endpoint, and credentials.\\
\hline
{\em out\+\_\+result} & Pointer to struct where the source pointer or an error message should be stored. Must not be NULL.\\
\hline
\end{DoxyParams}
