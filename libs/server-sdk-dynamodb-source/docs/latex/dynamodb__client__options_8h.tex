LDServer\+Dynamo\+DBClient\+Options\+Builder configures the AWS Dynamo\+DB client that a Launch\+Darkly Dynamo\+DB integration will use. 

All fields are optional. When left unset, the AWS SDK\textquotesingle{}s default provider chain (environment variables, shared config, EC2/\+ECS instance metadata) is used to resolve the corresponding field.

The builder is passed by handle to a Dynamo\+DB source or store factory, which takes ownership and frees it. Callers only need to call \mbox{\hyperlink{dynamodb__client__options_8h_ad01433c5bb604ccdfe6952a7b3f0cb94}{LDServer\+Dynamo\+DBClient\+Options\+Builder\+\_\+\+Free}} directly if the builder is not passed to a factory.

Sets the AWS access key ID for the Dynamo\+DB client. 

The only valid credential combinations are\+:
\begin{DoxyItemize}

\item Access\+Key\+Id + Secret\+Access\+Key + Session\+Token (STS temporary credentials).
\end{DoxyItemize}
