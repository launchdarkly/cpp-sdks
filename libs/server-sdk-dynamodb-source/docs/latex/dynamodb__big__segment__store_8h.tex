LDServer\+Big\+Segments\+Dynamo\+DBStore is a Big Segments persistent store for the Server-\/\+Side SDK backed by Amazon Dynamo\+DB. It is meant to be passed to the SDK via the Big Segments config builder. 

Call \mbox{\hyperlink{dynamodb__big__segment__store_8h_ad88d25d71da5206d53f3d1d002d8ab26}{LDServer\+Big\+Segments\+Dynamo\+DBStore\+\_\+\+New}} to obtain a new instance. This instance is passed into the SDK\textquotesingle{}s Big Segments configuration.

The Dynamo\+DB table must already exist and follow the Launch\+Darkly schema\+: a String partition key named {\ttfamily namespace} and a String sort key named {\ttfamily key}. The same table can be shared with \mbox{\hyperlink{dynamodb__source_8h_a6dee03c0b698272127b92379bbbdaec1}{LDServer\+Lazy\+Load\+Dynamo\+DBSource}} -- Big Segments rows occupy their own partition-\/key values and do not conflict with flag/segment rows. The Launch\+Darkly Relay Proxy populates Big Segments data in the table; this store only reads from it.
