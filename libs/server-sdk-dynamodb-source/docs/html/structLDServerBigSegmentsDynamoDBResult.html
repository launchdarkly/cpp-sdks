Detailed Description

Stores the result of calling LDServerBigSegmentsDynamoDBStore_New.

On successful creation, store will contain a pointer which may be passed into the LaunchDarkly SDK's Big Segments configuration.

On failure, error_message contains a NULL-terminated string describing the error.

The message may be truncated if it was originally longer than error_message's buffer size.

The message originates from the underlying AWS SDK and may echo back portions of the client configuration, including endpoint and region. Callers that surface this message (logs, telemetry, user-facing errors) may want to sanitize it accordingly.
