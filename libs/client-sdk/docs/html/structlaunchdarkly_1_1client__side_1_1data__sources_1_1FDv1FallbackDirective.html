Detailed Description

An instruction from the service to stop using FDv2 and fall back to FDv1.

FDv1FallbackDirective launchdarkly::client_side::data_sources::FDv1FallbackDirective::DefaultTtl ( )
static

Builds a directive using the jittered default TTL, so that SDKs which fell back together do not all retry at once. Used when the service supplies no usable TTL. Safe to call from any thread.
