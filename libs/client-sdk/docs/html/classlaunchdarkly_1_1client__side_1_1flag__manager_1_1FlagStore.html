Detailed Description

Holds the flag data the SDK evaluates against, plus the selector identifying the state of that data.

Thread-safe: every method may be called from any thread, and each call is atomic, so a reader never observes a partially applied write.

std::vector< FlagValueChangeEvent > launchdarkly::client_side::flag_manager::FlagStore::Apply ( FlagChangeSet const &  change_set,
bool  compute_changes 
)

Applies a changeset as a single unit.

The changeset's selector becomes the store's selector. A full or partial changeset carrying no selector clears it instead, because the resulting data no longer corresponds to a state the service can compute deltas against. A "none" changeset leaves the selector alone.

The first full data set the store receives is reported as no changes at all, since it is what the SDK starts from rather than a change to it.

Parameters
compute_changesWhether to report the resulting value changes. Pass false when nothing is listening for them, to skip the comparison.
Returns
The value changes the apply produced, in an unspecified order. Empty when compute_changes is false.
