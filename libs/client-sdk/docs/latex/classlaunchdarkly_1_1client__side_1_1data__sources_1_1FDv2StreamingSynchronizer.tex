\doxysubsection{Detailed Description}
Keeps flag data current over a long-\/lived connection to the FDv2 client streaming endpoint, turning the push-\/based event stream into the pull-\/based \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1IFDv2Synchronizer_a371aa6161cecbd98d9006dc10194ae91}{IFDv2\+Synchronizer\+::\+Next()}} interface.

Threading model\+: \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1FDv2StreamingSynchronizer_a72908696c4742ea25df5e1fa2ac2ad0e}{Next()}} should only be called once at a time. \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1FDv2StreamingSynchronizer_a08b9b354af74b0bab2573d396d0f1263}{Close()}} may be called concurrently with \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1FDv2StreamingSynchronizer_a72908696c4742ea25df5e1fa2ac2ad0e}{Next()}}. This object may be safely destroyed once no call to \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1FDv2StreamingSynchronizer_a72908696c4742ea25df5e1fa2ac2ad0e}{Next()}} or \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1FDv2StreamingSynchronizer_a08b9b354af74b0bab2573d396d0f1263}{Close()}} is in progress.

Returns a Future that resolves with the next result once it is available.

On the first call, the synchronizer starts its underlying connection. Subsequent calls continue reading from the same connection.
