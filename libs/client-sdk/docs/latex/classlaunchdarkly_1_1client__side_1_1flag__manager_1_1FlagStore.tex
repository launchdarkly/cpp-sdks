\doxysubsection{Detailed Description}
Holds the flag data the SDK evaluates against, plus the selector identifying the state of that data.

Thread-\/safe\+: every method may be called from any thread, and each call is atomic, so a reader never observes a partially applied write.

Applies a changeset as a single unit.

The changeset\textquotesingle{}s selector becomes the store\textquotesingle{}s selector. A full or partial changeset carrying no selector clears it instead, because the resulting data no longer corresponds to a state the service can compute deltas against. A \char`\"{}none\char`\"{} changeset leaves the selector alone.

The first full data set the store receives is reported as no changes at all, since it is what the SDK starts from rather than a change to it.
