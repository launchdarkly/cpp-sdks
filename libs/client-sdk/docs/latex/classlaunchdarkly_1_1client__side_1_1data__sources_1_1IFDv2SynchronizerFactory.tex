\doxysubsection{Detailed Description}
Builds new \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1IFDv2Synchronizer}{IFDv2\+Synchronizer}} instances on demand. Each call to Build() produces a fresh synchronizer that has not yet been started.

Implementations must be thread-\/safe. Build() and \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1IFDv2SynchronizerFactory_a1c00b326ed9e48136f130515ee06fe4c}{Is\+FDv1\+Fallback()}} may be called from any thread.
