\doxysubsection{Detailed Description}
Builds new \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1IFDv2Initializer}{IFDv2\+Initializer}} instances on demand. Each call to Build() produces a fresh initializer that has not yet been started.

Implementations must be thread-\/safe. Build() and \mbox{\hyperlink{classlaunchdarkly_1_1client__side_1_1data__sources_1_1IFDv2InitializerFactory_a999ce41b19e24d3171c1900e95556a87}{Is\+From\+Cache()}} may be called from any thread.
