\doxysubsection{Detailed Description}
The FDv2 data source. It runs a sequence of initializers to load flag data for one evaluation context, then hands off to a synchronizer to keep that data current, rotating synchronizers as they fail and recover.

The data source is built for a single evaluation context. Changing context means shutting this one down and starting another.

Lifecycle\+:
\begin{DoxyEnumerate}
\item Construct.
\item Call Start() exactly once. It returns immediately, and orchestration runs on the executor.
\item Call Shutdown\+Async() to stop. The completion runs on the executor once the source has stopped touching the store.
\end{DoxyEnumerate}

Thread safety\+: Start, Shutdown\+Async, and Environment\+Id may be called from any thread.
