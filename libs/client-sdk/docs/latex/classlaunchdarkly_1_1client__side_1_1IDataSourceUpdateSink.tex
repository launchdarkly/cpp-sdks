\doxysubsection{Detailed Description}
Interface for handling updates from Launch\+Darkly.

Implementations must be thread-\/safe. A data source calls these from whichever thread it runs on, concurrently with flag evaluation and listener registration on the application\textquotesingle{}s threads.
