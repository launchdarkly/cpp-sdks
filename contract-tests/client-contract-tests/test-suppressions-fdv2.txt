# The event processor gates SendAsync on an inbox counter sized at the events
# capacity, so a burst that outruns the io_context drops events before they
# reach the summarizer. This test sends a full buffer of custom events and then
# evaluates a flag, and under FDv2 the busier startup makes the evaluation lose
# that race, so no summary event is produced. The outbox itself already keeps
# the summary when it overflows. The inbox is the gap.
events/event capacity/summary event is still included even if buffer was full
